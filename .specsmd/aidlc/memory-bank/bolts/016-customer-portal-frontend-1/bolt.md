# Bolt: Customer Portal Frontend (016-customer-portal-frontend-1)

## Objective
Build the responsive mobile/desktop customer portal enabling EV drivers to manage their registered vehicles (plates and RFID tags), monitor live charging sessions, view session history, and inspect receipts.

## Stories Covered
- `001-customer-registration-profile.md` (FR-FE-11)
- `002-vehicle-rfid-management.md` (FR-FE-12)
- `003-active-charging-session-monitor.md` (FR-FE-13)
- `004-session-history-invoices.md` (FR-FE-14)

## Execution Tasks
1. Implement Customer Registration and profile management interface.
2. Implement Vehicle & RFID card registry interface with add/edit/de-list actions.
3. Implement Active Charging Session view displaying live kWh delivered and cost calculations.
4. Implement Charging Session History table with monthly filters and itemized receipt modal.
