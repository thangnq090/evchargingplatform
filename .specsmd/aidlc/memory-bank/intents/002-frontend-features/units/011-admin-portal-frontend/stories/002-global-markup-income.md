# Story: Global Markup & Income Dashboard

## Story ID
`002-global-markup-income`

## Unit
`011-admin-portal-frontend`

## Requirement Mapping
- **FR-FE-2**: Platform Admin can configure global markup percentages/fixed rates added to vendor base prices, and view platform-wide income aggregated over custom date ranges.

## Acceptance Criteria
1. Admin can view current platform markup rate (percentage and fixed Cents/kWh).
2. Admin can edit and save the platform markup rate with instant form validation and confirmation dialog.
3. Financial dashboard displays total platform income, total kWh delivered, active vendor counts, and average profit per session.
4. Date range filter (Today, 7 Days, 30 Days, Custom Range) dynamically refreshes financial summary metrics and income trend charts.
