# Story: Cross-Tenant Full-Text Search Bar

## Story ID
`004-global-fts-search`

## Unit
`011-admin-portal-frontend`

## Requirement Mapping
- **FR-FE-4**: Platform Admin can perform full-text search across all sessions, plates, customer account numbers, and error codes.

## Acceptance Criteria
1. Header navigation includes a prominent Global Search bar accessible from any Admin screen.
2. Typing partial terms (e.g. "AUD", "ERR_1001", "ACC-992") displays real-time auto-complete search results categorized by Session, Customer, Vehicle Plate, and Error Code.
3. Clicking a search result item navigates directly to the detailed drawer or page view for that entity.
4. Includes full search page with advanced filters (date range, status, vendor scope).
