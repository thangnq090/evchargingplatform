# Story: Chargepoint Management & Grouping

## Story ID
`001-chargepoint-management`

## Unit
`012-vendor-admin-frontend`

## Requirement Mapping
- **FR-FE-5**: Chargepoint CRUD management, connector configuration, group label assignment, and base unit pricing configuration in tenths of cents per chargepoint or group.

## Acceptance Criteria
1. Vendor Admin can view, add, edit, and soft-delete owned chargepoints in a searchable, filterable data grid.
2. Vendor Admin can assign dynamic group labels/tags to chargepoints for bulk management.
3. Vendor Admin can configure base pricing per kWh (specified in tenths of cents) at individual chargepoint level or group level.
4. UI validates numeric pricing input and handles connector state toggles smoothly.
