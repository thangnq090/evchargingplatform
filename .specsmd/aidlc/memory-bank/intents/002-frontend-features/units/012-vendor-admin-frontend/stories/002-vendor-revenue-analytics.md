# Story: Vendor Revenue Analytics

## Story ID
`002-vendor-revenue-analytics`

## Unit
`012-vendor-admin-frontend`

## Requirement Mapping
- **FR-FE-6**: Vendor financial analytics breakdown including total income, platform markup deductions, net revenue, and session statistics over daily, weekly, and monthly views.

## Acceptance Criteria
1. Vendor Admin can view summary KPIs for total gross revenue, platform markup fees, net payout, and total charging session counts.
2. Interactive time-series charts display revenue breakdown and session counts aggregated by daily, weekly, and monthly timeframes.
3. Chargepoint revenue leaderboard shows highest performing charging stations/connectors.
4. Export financial summaries as CSV or PDF report format.
